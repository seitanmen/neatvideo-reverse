# FUN_00995250 の方向フィルタ部の演算 (解読メモ、sandbox/dirfilt)

逆アセンブル `notes/disasm_995250.txt` を読んで移植 (`src/nv_model.py`) に落とした手順。すべて float32。
「観測」は `nvh model` とのビット一致で確かめた。意味づけ (「頑健化」など) は推定。

## 前処理 (語 0..54 の前、0x99568c〜)
- 段 k ごとに src_k を箱 3 (FUN_009944c0 r=1 mode 0、行→列) → 2×2 平均 (FUN_009f15b4) → lo、band_k = src_k − up2(lo)
  (FUN_00990da8)。帯域ピラミッドは全段を先に作る。
- 段ごとに E_k = √|箱3_0詰め(band_k²)| (0x75c0)。段統計 (nv_band) はこの E_k の切り出し。

## 族 A (組 s = 1..4、段ごと)
方向 d ごと (K_d = FUN_00990448 の線カーネル、角度は組の表):
1. T = band − linefilt(K_d, band, r=4, mode 1)
2. フラグ組 (3, 4): T = √|箱3(T²)| (行→列)、c = 0.75。それ以外は c = 1.0 (T のまま)
3. t = c · (C_k · (|q99_k| · 1.1))、C = DAT_012445a8 (1.06, 1, 1, 1, 1)、q99_k は語 5+k (外挿値なら負なので絶対値)
4. G = FUN_009ef0d0(t, band, T): z = (1/t)·T、|z| > 1 なら band / z² (NEON 部は FRECPE + FRECPS 1 回の逆数、端数部は除算)、それ以外 band
5. F_d = 線フィルタ(K_d, G, 4) (2 段目がある方向は続けて K_idx2 を rad2 で)
6. E_d = √|箱(F_d², rs)| (rs = 1。フラグ組は 箱→箱 の 2 回)
7. フラグ組: F_d += 線フィルタ(G − F_d)
8. 語 A[s][k][d] = fmaxnm(分位点 0.99 (端 4・div は組の表), 1e−6)、E_d ← E_d · (1/q)
- argmax (FUN_009ee5fc、≥ で後の方向が勝つ、無順序比較は更新しない) で S = F_argmax、R = band − S
- 語 R[s][k] = q99(√|箱3(箱3(R²))|) (段統計と同じ端 4・div 4)
- dc (組 2..4): W, H > 2·4 かつ端 (4/6)・面積 (8·div) の条件で
  t = (|q99_k| · C_k) · 1.25、Q = FUN_009ef0d0(t, R, E_k)²、箱 (半径 4、フラグ組は 2 回)、√|·|、q99 (div 16 / 36) → 語 dc[s][k]

## 族 B / C (組 3, 4 / 組 4)
- U = band_k + up2(band_k+1) (最後の段は 0)、V = k = 0 なら (U + 箱3(U))·0.5、それ以外 U
- 方向 d: F_d = 線フィルタ(K_d, V, r) (B: 6、C: 12)、E_d = √|箱(箱(F_d², 2), 2)|、語 = q99 (端 6 / 12、div 24 / 48)
- C のみ: F_d = 線フィルタ(K_d, U, 6)、argmax で S、M = (band + U) + fma(S, 1, 0) (FUN_009ed978) → FUN_00ad319c(band, M)

## 外挿 (測れない段 k > 0)
値 = (前段 == −1e6) ? −1e6 : fac · (−|前段|)。fac は段統計の外挿係数と同じ (測れた段では |q99_k / q99_k−1| を [0.5, 1] に)。
族 A が測れないときは A の全方向・R・dc を、B / C はその族の全方向を外挿する。k = 0 で測れなければ初期値のまま。

## 無順序比較 (NaN) の扱い (観測。照合で必要だった)
fcmp の結果が無順序のとき NZCV = 0011 なので、b.le・b.lt・b.hi・b.ne・b.cs は成立、b.eq・b.mi・b.gt・b.ge は不成立。
FUN_009ef0d0 の端数部 (b.le) は z が NaN なら band をそのまま返し、FUN_00ad319c のスコア更新 (b.le で飛ばす) は NaN を採らない。
