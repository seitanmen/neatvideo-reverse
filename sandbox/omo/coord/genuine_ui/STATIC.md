逆コンパイルの保存先は `static/decomp/`・`static/decomp_full/`、使ったスクリプトは `static/scripts/`。

## 1. ビューアの表示変換

### 1a. モードとペイン (観測)
- モード (`+0x1d8`): 0 Normal / 1 YCrCb+ / 2 RGB / 3 YCrCb / 4〜6 Y・Cr・Cb Freq。
- 周波数画像の種類 (表 0xc943f8): モード 1 → 4 (帯域の和)、4→1、5→2、6→3。それ以外は周波数画像なし。
- ペインの id (`FUN_00089bf0`):
  - 主ペインは 0 (Normal)。
  - YCrCb+ 16/17/18。YCrCb 4/5/6。Y Freq 7〜9、Cr Freq 10〜12、Cb Freq 13〜15 (それぞれ High/Mid/Low)。
  - RGB: 1+3 では R, G, B の順。2×2 では右上 G・左下 R・右下 B。

### 1b. 色変換 (観測・確度高)
- `0x97b5d0`: Y = 0.2989R + 0.5866G + 0.1145B、Cr = (R−Y)·0.71316504、Cb = (B−Y)·0.56465274。オフセットはなく、Cr/Cb は 0 中心の符号付き。入力は 0〜255 の RGB。
- Normal・R・G・B は色変換しない。
- Freq と Enhanced は、プロファイルの色モード (+0x48) で変換を選ぶ。既定の 1 は上と同じ式、0 はコピー、2 は Y=(R+G+B)/3、Cr/Cb=(R−Y)·0.75 / (B−Y)·0.75。

### 1c. ペインごとの写像 `FUN_00051130` (観測・確度高)
- 表示値 = sat_u8(round(gain_c·v + off_c + d))。d は ±0.25 程度のディザ (表 16384 個、種 0x93f02c74)。
- 出力範囲 [下端 → 上端] (R, G, B):

  | 種類 | id | 下端 | 上端 |
  |---|---|---|---|
  | Y 系 (Normal を含む) | 0・4・7〜9・16 | (−0.5, −0.5, −0.5) | (255.5, 255.5, 255.5) |
  | R | 1 | (−0.5, −0.5, −0.5) | (255.5, 200.5, 200.5) |
  | G | 2 | (−0.5, −0.5, −0.5) | (200.5, 255.5, 200.5) |
  | B | 3 | (−0.5, −0.5, −0.5) | (200.5, 200.5, 255.5) |
  | Cr 系 | 5・10〜12・17 | (31.5, −0.5, −0.5) | (255.5, 215.5, 225.5) |
  | Cb 系 | 6・13〜15・18 | (−0.5, −0.5, 15.5) | (235.5, 225.5, 255.5) |

- 明るさスライダー b: 0〜100、既定 50。
- (A) id < 5 (Normal・R・G・B・Y):
  - mn/mx は元画像の全チャンネルの最小・最大を ±2048 に制限したもの。
  - b > 50 のとき、f = (b−50)/50。入力範囲は [lo, hi] = [f·mn, f·(mn + 0.33(mx−mn)) + (1−f)·255]。出力の下端に +32f を足す。
  - b ≤ 50 のとき、f = (50−b)/50。入力範囲は [lo, hi] = [f·(mx − 0.33(mx−mn)), f·mx + (1−f)·255]。出力の上端から 32f を引く。
  - [lo−0.5, hi+0.5] を [下端, 上端] へ線形に写す。b = 50 では恒等。
- (B) id 7〜18 (Freq と Enhanced):
  - s = b/75 + 1/3 (b ≤ 50)、b·0.04 − 1 (b > 50)。
  - (L, H) は面 k の表示範囲 (L = H なら (L+1, H−1))。
  - out = m_c + s·h_c·(2(v−L)/(H−L) − 1)。m_c、h_c は出力範囲の中心と半幅。
- (C) id 5・6 (YCrCb の Cr・Cb): s' = b/50 として out = m_c + s'·h_c·v/64.5。

### 1d. Frequencies と Enhanced (観測・確度高)
- 呼び出しの流れ: ジョブ種別 9 → `FUN_0014f9a0` → BuildFreqImage (`0x9b0b68`) → FindFreqLevs (`0x9b2814`)。出力は 16 ビット型 (深度 1)。
- 面ごとの分解 `FUN_009987ac` (nv_band と同じ部品: 半径 1 の箱 `9944c0` ×2、縮小 `9f15b4`、`990da8`、`993df0`):
  - 5 段 (k = 0..4): band_k = x_k − up(x_{k+1})、x_{k+1} = 縮小(3×3 箱(x_k))。
  - Freq: k = 0, 1, 2 の帯域を元の解像度まで拡大し、High/Mid/Low にする。
  - Enhanced: S = Σ_{k=0..4} w_k·up^k(b̃_k)。最後の低域 x_5 は含めない。
    - 強調あり: b̃ = b / ((Box3(Box3(b²)))^{1/4} + 0.01)、w_k = 1.25^k。
    - 強調なし: b̃ = b、w_k = 1。
  - 強調が入るのは Prepare ページの YCrCb+ で、page+0x1e0 == 0 (Profile Check 中でない、推定) のとき。Adjust ページの YCrCb+ は帯域の単純な和。
- 表示範囲 `FUN_009b2814`:
  - 面ごとに、ヒストグラム (1/16 刻み) の分位点 q30・q70 と、正規近似 g = μ + σ·Φ⁻¹(0.3 / 0.7) を求める。
  - 20·|q70−q30| < |g70−g30| のときは q と g の平均を使う。
  - d = max(|q70−q30|, m)。m は Freq で 0.25、Enhanced で 1.0。
  - 範囲は (q30+q70)/2 ± 4d。Enhanced の Cr・Cb だけ ±8d。
  - Enhanced の Y だけ、さらに 1%/99% 分位で切る (|p99−p1| > 0.01 のとき)。

### 1e. その他
- ビューアにはガンマの操作がない。下段の γ ボタンは Input Data Gamma (処理側の設定)。
- 色モードの表 0x147dfd0 (成分名と色): Y (255,255,255)・Cr (255,128,128)・Cb (128,128,255)、RGB は原色。グラフや警告の名前に使うとみられる。

## 2. 選択範囲 (Prepare ページ)
- サイズ表 0xc94650: 辺 15/31/63/127/191/319/511/512。
- 上限 (観測・高): ドラッグの起点から各辺 512 まで、かつ画像内に制限する (`FUN_0004dea8`)。下限の制限はない。Adjust の preview 範囲は 47〜1280 (表 0xc944b0)。
- 色 (`FUN_000492d4`、比較は min(w,h) とみる。中高):
  - ≤ 15: 赤 (255,15,15)、外側 (128,0,0)、破線。
  - 16〜127: 黄 (255,208,15)、外側 (100,97,2)。
  - ≥ 128: 緑 (15,192,15)、外側 (0,94,0)。
  - 無効のときは灰 (192 と 64)。
  - Main Sample (プロファイルに使った領域) と一致するときは別の色。値は実行時に決まり未特定。観測では青。
  - 青 (15,15,255) は Adjust の preview 範囲の色。
- Noise Level (観測・高、`FUN_001576c0` → `FUN_009b01d4`):
  - NL = √( Σ_{k=0..4} Σ_{c∈RGB} mean_{c,k}² )。mean は `nv_band.model_levels(plane)` の語 0..4 (端 4px を除いた段 k の局所 RMS の平均)。面は選択範囲の RGB (0〜255、色変換前)。
  - 表示は "Noise Level: " + 小数 1 桁で、min(w,h) ≥ 16 のときだけ。
  - 後ろの " (%+d%%)" は (NL / プロファイル側の値 − 1)·100 を 0 方向に切り捨てた値 (基準値 `FUN_009bab0c` は未読)。
- Not Uniform (観測・高): 選択範囲をプロファイルの色モードで変換し、各面で `nv_band.band_levels` → `nv_flat.flatness` を計算する。2.0 以上の成分名を並べる (YCrCb の輝度フラグは (1,0,0))。
- Clipping: IsClip が 0.33 を超える R/G/B を並べる。
- どちらも設定のフラグで表示する。

## 3. 1+3 Bottom の下段 (観測・高、中心合わせは中高)
- 配置:
  - 1+3 Bottom: 主ペインが上段で 3 列にまたがる。列の比 1:1:1、行の比 2:1。
  - 1+3 Right: 列の比 2:1。2×2: すべて 1。
- 倍率: 下段は主ペインと同じ倍率。
- 位置:
  - 選択があれば、その中心 ((x0+x1+1)/2, (y0+y1+1)/2) を下段の表示の中心にする。
  - なければマウスに追従するか、主ペインの中心に合わせる。
  - 下段どうしは同じ位置。2×2 は全ペインが同じ位置。

## 4. 正方形でない領域 (観測・高)
- 選択からのプロファイル作成は、x0, y0, w, h をそれぞれ独立に切り出して BuildNoiseModel に渡す。正方形の判定はない。
- repro の移植も 200×150・160×90・97×71 で本家とビット一致 (`model_verify/verify_profile.py`)。
- 大きさの制限 (`FUN_000cfba0`):
  - min(w,h) < 32: エラー「Too small area… at least 32x32」。
  - 32〜127: 警告「推奨 128x128」(「Use the small area」/「Cancel」)。
  - Fine-Tune は 16 以上。
