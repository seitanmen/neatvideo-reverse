# ハーネス追加要求 (WP temporal)

日付: 2026-10-17 / 対象: `analysis/harness/nvh.c` (こちらでは変更しない。`make` も実行しない)

## 目的

時間フィルタ (FilterTemporal, 0x9a4800 → 0x9a815c → CPU 0x9a84f8) の移植
(`sandbox/omo/wp_temporal/src/nv_temporal.py`) を本家と数値比較できるように、
葉の数学関数を単体で呼ぶサブコマンドを追加してほしい。

## 要請 A: 葉の数学関数 5 個 (保護判定なし。差分案 `nvh_patch.diff` 参照)

| サブコマンド案 | 本家関数 | 観測した呼び出し形 | 根拠 (逆アセンブル/逆コンパイルの範囲) |
|---|---|---|---|
| `ramp t in.f32 n out.f32` | `FUN_009ee93c` | `(t, 2t, 1.0, 0, out, in, n)` (float 4 + ptr 2 + n) | 0x99b408 の呼び出し (`notes/dis/fn_99afb4.s` 258-278 行付近)。本体は fmul/fadd/fcmp/fcsel のみ (`rtti/kern/fn_0x9ee93c.c`) |
| `wmul t prev.f32 r.f32 n out.f32` | `FUN_009eebf8` | `(out, prev_w, r, n, t, 2t, 1.0, 0)` | 同上 0x99b3f0 の呼び出し。本体は乗算結合のみ |
| `pairw c a.f32 b.f32 cc.f32 n out.f32` | `FUN_009efb1c` | `(c, a, b, cc, out, n)` → `out[i] = c·cc[i]·(max(a[i],b[i])−b[i])` | 0x9a84f8 内の呼び出し。`notes/dis/fn_9efb1c.s` 全文 (NEON fmax/fsub/fmul + スカラー尾部、分岐なし) |
| `sizes W H` | `FUN_0099c3a4` | `(out_long12, W, H)` → 幅 6 + 高さ 6 | `rtti/kern/fn_0x99a76c.c` 67 行目の呼び出し。表計算のみ |
| `down2 W H plane.f32 out.f32` | `FUN_009f15b4` | `(dst_coarse, src_fine, W_fine)`、dst のストライドは W>>1 | `fn_0x99a76c.c` 118-126 行目のループ (lVar40 += (W>>1)*4) |

- いずれも入力は float 平面ファイル (既存 `load()` 流用)、出力は `dump_f32`。
- 引数の順 (out/in の前後) は逆アセンブルからの推定を含む。ビルド後に
  in≠out の平面で 1 回試し、逆なら入れ替えて検収してほしい (ramp/wmul)。
- 落ちる入力: 報告済みの範囲では無し (純計算)。n=0 は呼ばない側で弾く。

## 要請 B: 段の重み (保護判定を「含む」が回避しない — 統括判断)

`FUN_0099afb4` (段の重み) と `FUN_0099a76c` (類似度) を丸ごと呼ぶサブコマンド。
どちらも内部に難読化された読み (`DAT_01488020` 系の語の読み出しと
`BYTE_ARRAY_ARRAY_015b2719` 系への書き戻し、`17 − popcount` 係数) があるが、
**判定を飛ばしたりパッチしたりせず、そのまま実行する**。これは既に許可済みの
`nvh flat` (FindFlatArea 内のカウンタ 0x1488348 と同じ類) と同種の使い方。

- 呼び出しに必要な入力: 差分面 1 枚、σ² ピラミッド (段ごとの面)、σ 構造体 (5 float)、
  s_k、T²、モード (`DAT_012453e8` の表)。σ² ピラミッドは `FUN_009aae90` が
  インスタンスを必要とするため、当面は**呼び出し側で与えた平面**を使う
  (本物の σ² との一致は問わない。関数の数式の一致だけを見る)。
- 差分案は添えていない (引数が 16 個あり、σ² 構造体の初期化が未確定のため)。
  承認されるなら統括側で σ 構造体のメモリ (0x28 バイト、+0x14 に 4 float) を
  calloc して渡す形を想定している。

## 要請 C: 3×3 平均平方根 (`FUN_009950f4`)

`99afb4` から `FUN_009950f4(1.0f, buf, x1, &o1, &o2, 1, flag)` の形で呼ばれる
