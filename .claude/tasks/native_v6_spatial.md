# v6 空間フィルタ実装仕様 — 本家 FUN_0098edb0 の C++ 移植 (Phase B 成果)

作成: 2026-11-02 (統括)。Phase B の構造解読 (work/omo/wp_genuine_decode/PHASE_B_PROGRESS.md)
に基づく、本家と同じ空間フィルタの C++ 実装仕様。

## 1. 対象

本家 FUN_0098edb0 (arm64、0x98edb0〜) の 1 面あたりの処理を C++ で再現する。
入力: 1 面の画素配列 (float32、0〜255)＋モデル面 (4096 語)＋cfg (フィルタ設定)＋組番号。
出力: 処理済み 1 面。

## 2. 処理の流れ (Phase B で確定した構造)

```
1. 白色化: W[i] = B[i] / (σ[i] + 1e-4)
   σ[i] はモデル面の帯域ブロックから (FUN_009ed5f8 = 1/(x+1e-4) refine 葉で実行)
   1e-4 = 0x38d1b717
2. 帯域ごと (k = 0..4):
   t  = (cfg[k] + 1e-6) × |model[0x14/4 + k]| × 1.1     # 1e-6 = 0x358637bd
   R  = FUN_009950f4(W²)                                 # √(3×3 mean(W²))
   X  = FUN_009eebf8(W, R, t, 2t)                        # X = W·clamp(2 − R/t, 0, 1)
   if 方向経路の条件を満たす (組+0x284 > 0 かつ 組+dir×8+0x348 にカーネルあり):
       方向経路 (下記 3) を実行
   else:
       amount 適用 (下記 4)
3. 出力: X (白色化×量 適用済み) を B に書き戻す
```

## 3. 方向経路 (組ディスクリプタにカーネルがある場合)

```
s0 = 1/(4.5·t)                          # FUN_009eef5c (rinv 葉)
dir ループ (dir = 0..[sp+0x188]):
    buf = scratch + dir×0x3830
    FUN_009944c0(out=buf, src=帯域, kernel=組ベース, dir_data, w=1)
        # 線フィルタ実行 (nv_curve の線フィルタと同じ関数)
    op = 組+dir×8+0x348 の値             # −1 = スキップ / 0 = rstep / 1 = 頑健化
    if op == 0: 何もしない (方向成分をそのまま残す)
    if op == 0 → FUN_009ef260 (rstep 葉) を buf に適用   # 0 = rstep
    if op == 1:
        FUN_009ed710(buf, 線フィルタ結果)  # buf = 帯域 − 線フィルタ
        FUN_009950f4(scratch, buf)         # √(3×3 mean(差²))
        FUN_009ef0d0(scratch, buf)         # 頑健化 (FRECPE 系除算)
    # 第 2 カーネル
    k2 = 組+dir×8+0x3c8 の値
    if k2 != 0:
        FUN_009944c0(out=buf2, src=..., kernel=k2, dir_data2, w=1)
    # マスク付き 3×3 箱 (FUN_009ed014) ループ
    # FUN_009ba54 (コピー) → FUN_009bf40 (合成)
正規化: FUN_009ed4e0(buf, √|x|·1/モデル重み) — モデル重み = model + 組×0x140 + k×64 + dir×4 + 0x140
減算: FUN_009ed710(帯域, 方向成分)
```

## 4. 量の適用 (3 択)

```
dir_applied = 方向経路を実行したか (0/1)
if cfg[+0xb8] > 0 AND cfg[+0x14+4k] != 1.0:
    # 適応経路: FUN_009ee7bc
    a  = cfg[+0xb8] × (1 − cfg[+0x14+4k])
    b  = −1.0; lo = −1.0; hi = −cfg[+0x14+4k]
    X  = clamp(b + a·W, lo, hi) × X            # FUN_009ee7bc = clampmul 葉
else:
    amount = (1 − dir_applied) × (−cfg[+0x14+4k])
    X  = X × amount                             # FUN_009ee304 = scale 葉
```

## 5. 組テーブルの実データ (reference/genuine/NeatVideo6.arm64.ofx の __TEXT __const @ 0x1243700)
