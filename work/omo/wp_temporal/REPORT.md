### 1.2 設定値の単位 (質問 d)
- 結論 (観測、`param_1[0x7a0]` の設定構造体):
  - `+0x168` (int) が 1 のとき T² = **64.0**、それ以外は T² = (`*(float*)(+0x160)` × 0.16)²。
  - `+0x0d4` (float) = σ 既定値。`+0x0e0` (float) = 段係数 s_k (全段共通、最粗段のみ ×1.3)。
  - `+0x12c` / `+0x300` (float) は 1.0 以外のとき重みに `FUN_009ee304` を適用。
  - `+0x130` (int) = 類似度モード → `DAT_012453e8 + mode*0x10`。`+0x22a6` = 差分合成モード →
    `DAT_0147dfb0 + mode*8` (モード 0 = G 面、1 = BT.601 輝度、2 = 3 面使用。§6.4 と整合)。
- 範囲: `fn_0x9a84f8.c` 176-215 行。

### 1.3 σ_k の出所 (質問 a)
- 結論 (観測): 段の閾値は `FUN_0099afb4` 内で
  `t = C_k × 1.1 × s_k × 1.2806249 × 0.9 × (17 − popcount) × |σ_k| + T²_in`、
  `σ_k = *(float*)(σ構造体 + 0x14 + 4k)` (fabs 付き)。σ 構造体は 9a84f8 のスタック `local_190` で、
  モード (`+0x168`) に応じて `settings+0xd4` の値と 100.0 を 5 float へ配る (0x42c80000 = 100.0f を確認)。
  定数はビット列で確認: `0x3f8ccccd`=1.1、`0x3fa3eb84`=1.2806249、`0x3f666666`=0.9、`0x38d1b717`=1e-4。
  `(17 − popcount)` は 2 箇所 (99afb4 内部と 99a76c の最粗段呼び出し側) にあり、正常時 1 と仮定
  (**仮定**。規約により追跡・回避はしていない)。
- 未解読: σ² の**画素単位**ピラミッド `FUN_009aae90` が使うインスタンス側の表
  (`+0x11548+4l`、`+0x1349c+4l`、`+l*0x404+{0,0x14,0xb8}`) を書くコードが既存の逆コンパイルに無い。
  `/tmp/nv_expand/disasm_full.txt` の grep でも即値は出ない (ARM64 の即値分割のため)。要相談 1。
- 範囲: `notes/dis/fn_99afb4.s` 100-300 行、`fn_0x99a76c.c` 末尾、`fn_0x9a84f8.c` 186-215 行。

### 1.4 フレーム別 (ゲイン, オフセット) (質問 b)
- 結論 (観測): 9a84f8 は近傍フレームの差分を `FUN_009aba00(gain, offset, …)` で作る。ゲインは
  `param_1 + slot*0xb + 0x47f9/0x47fc/0x47fe` (3 面)、オフセットは `param_1 + slot*0x58 + 0x23fcc/0x23fdc/0x23ff4`。
  対 (pair) の 2 本目はゲインの符号を反転して使う箇所がある (`fVar81 = -*(float*)(…+0x47f9)`)。
  中心は `FUN_009abbe4(-1,0,-1,0,-1,0,…)` で −中心 を作る (§6.4 の記述と一致)。
- 未解読: これらの配列を**計算する**コード (フレーム間の輝度較正) は未特定。読み出し側のみ観測。要相談 1。

### 1.5 重みの合成と出力の正規化 (質問 c)
- 結論 (観測):
  - `FUN_0099a76c`: 差分を 4 段ピラミッドに分解 (`FUN_0099c3a4` サイズ表、`FUN_009f15b4` 1/2 縮小、
    `FUN_00990da8` 帯域分解)、**k=3 (最粗) から k=0 へ** `FUN_0099afb4` を呼び、段間で
    `FUN_00993df0` により重みを細かい段へ拡大する。最粗段のみ T² を加算。
  - `FUN_0099afb4`: X = 差分/(σ²+1e-4)、R = √(3×3 平均(X²)) (`FUN_009950f4` を 1.0 初期化で呼ぶ)、
    w = clamp((2t−R)/t, 0, 1) (`FUN_009ee93c`)、前段の重みがあれば `FUN_009eebf8` で乗算。
  - 対の重み: `FUN_009efb1c(c, a, b, cc, out, n)` → `out[i] = c·cc[i]·(max(a[i],b[i])−b[i])`
    (全文解読、`notes/dis/fn_9efb1c.s`)。
  - 蓄積: `FUN_009ed844` (Σw)、`FUN_009edadc` (acc + f·w²)。残留ノイズ Σf·w²/(Σw)²。
  - 最終正規化 `FUN_009abfd4`: 行ごとに `FUN_009ed3e0` → モード別 (`9f0f9c`/`9f0e08`、`[x25]` に 3 面分の
    (スケール, オフセット)) → `s0 = 1/(2·off − acc)` (等しければ 1.0) → ×255.0 (`0x437f0000`) /
    −255.0 (`0xc37f0000`) → `FUN_009f1110` で固定小数点 (int16) 出力。
- 未解読: `9f0e08`/`9f0f9c`/`9f1110` の中身、方向フィルタ部 (0x99afb4 後半、`DAT_01243988` 系) の合成式。
