- 方向経路は「帯域から方向成分を推定して引く」処理:
  各方向の線フィルタ → 頑健化 → 2 乗 → マスク箱 → 正規化 (√|x|·1/重み) →
  帯域から減算。モデルの方向重み (model + 組×0x140 + k×64 + dir×4 + 0x140) で
  正規化するのが本家の設計。
- v5 (a-trous + Wiener) にはこの構造がなく、E9 の差の主因と整合する。
- v6 実装に必要な残り: FUN_009944c0 の呼び出し規約の詳細、
