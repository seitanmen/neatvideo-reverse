## 条件

  sintel (Sintel © Blender Foundation, CC-BY 3.0。予告編の元フレーム 571〜630。粒状 σ≈0.2。上下に黒帯)。

  frame 0 で Auto Profile → Auto Fine-Tune、フィルタは既定値。出力は 16 ビット RGB の TIFF

## 2. 除いた量の中身 (`tools/diag_removed.py`、全表は `eval/diag_tables_progressive.md`)

記号: 足した雑音 n = 雑音入り − 正解、除いた量 m = 雑音入り − 出力。
- ρ = corr(m, n)
- β = ⟨m,n⟩/⟨n,n⟩ (足した雑音のうち除いた割合)
- ρ² = 除いた量のうち雑音の占める割合
- 他 = RMS(m − βn) (除いた量のうち雑音以外: 画・素材の粒状・動きの誤り)

\* sintel の「残り」の雑音が大きいのは、黒帯で雑音が 0 で切られて平均がずれる (+1.58) ためで、直流に近い成分である。

観測:
- 動きの区分 (park_joy p_y3、大きく動く画素が 72%): 大きく動く区分の「他」は、当方 7.09 に対し本家 2.00。β は当方 0.82、本家 0.46。
- 本家の除いた量は、どの帯域でも足した雑音の RMS 以下で、粗い帯域ほど β が下がる (park_joy p_y3: 帯域 1 が 0.55、帯域 5 が 0.40)。
  当方は粗い帯域と低域で、足した雑音の 2〜15 倍を除いている (park_joy の帯域 5 で 7.5 倍、低域で 15 倍。sintel の帯域 4・5 で 2 倍)。
- 本家は雑音を取り残す (β 0.54〜0.83) 代わりに、画をほとんど削らない。当方は雑音を多く除く (β 0.80〜0.90) が、画も削る。
- 推測: 当方が低域まで除くのは、動きを補償しきれていない時間方向の混合 (ゴースト) と、粗い帯域で雑音を過大に見積もっていること
  (`eval/diag_profile_*.json`: 帯域比が粗い帯域で 2.6〜5 倍) によるとみられる。

## 3. 粒状と静止区分のフレーム差 (`tools/diag_temporal.py`)

old_town p_y3 の静止区分 (画素の 45%)、フレーム t と t−1 の差 d で見る:

| | d の RMS | 正解の d を残す割合 keep_clean | 足した雑音の d を残す割合 keep_added |
|---|---|---|---|
| 正解 | 5.28 | 1 | – |
| 足した雑音 | 4.26 | – | 1 |
| 当方 | 1.55 | 0.13 | 0.06 |
| 本家 | 2.14 | 0.17 | 0.08 |

(σ6 では当方 1.64 / 0.12 / 0.06、本家 2.63 / 0.17 / 0.08。)

観測と解釈:
- 正解自身のフレーム間の揺らぎ (5.28) は、静止部では主に素材の粒状とみてよい。どちらの処理も、これを 8 割以上消している
  (残すのは当方 13%、本家 17%)。足した雑音の揺らぎも同じ程度に消している (当方 6%、本家 8%)。
- 静止部のフレーム差が当方 1.55、本家 2.14 と違うのは、本家が粒状を見分けて残しているからではない。本家の時間フィルタが、
  粒状も雑音も一様にやや弱めに残すためである (keep_clean と keep_added がどちらも当方の約 1.3 倍)。
  粒状と足した雑音は時間方向にどちらも独立なので、区別できないのは当然である (推測ではなく構造上の事実)。
- old_town の除いた量の「他」も、当方 3.69・本家 3.39 と近く、どちらも粒状 (白色換算 σ 3.0) をほぼ同じだけ削っている。
  したがって old_town で正解比が入力より悪くなるのは、本家にも共通の性質である (本家も y3 で 37.42 < 入力 38.55)。
- park_joy (静止は 2% だけ) では、正解の揺らぎを残す割合が当方 0.37 に対して本家 0.70 で、大きく違う。こちらは粒状ではなく、
  動きのある画を時間方向に混ぜるか (当方) 混ぜないか (本家) の差である。

## 4. 色差の手がかり

当方の色差の悪化のうち、プロファイルが雑音を見積もり過ぎていること (`diag_profile`。CHROMA_GAIN Cb 3・Cr 4 で、
sintel でも実際の雑音の 2.4〜4.4 倍、park では 10 倍超) は既報のとおり。本家の出力から読めることは次のとおり。

観測 (Cb・Cr、除いた量。全表は `eval/diag_tables_progressive.md`):
1. 全体の量:
   - 本家: 除いた量は足した雑音とほぼ同じか少ない (sintel p_y3 で Cb 1.18 / 1.26、Cr 1.23 / 1.29)。β は 0.84〜0.93 (sintel・old_town)。
   - 当方: β は 0.95〜1.0 で雑音はほぼ全部除くが、除いた量は雑音の 1.2〜3.7 倍で、色の画も削っている。
2. 帯域の形:
   - 本家: β は粗い帯域ほど下がる (sintel Cr: 帯域 1〜4 で 0.91 / 0.84 / 0.71 / 0.50。old_town Cr: 0.92 / 0.87 / 0.82 / 0.78)。
     除いた量はどの帯域でも雑音の RMS 以下である。
   - 当方: β が 0.9〜1.0 で帯域によらずほぼ一定。粗い帯域では雑音の 1.5〜5 倍を除き、低域 (残り) まで削る (sintel Cr の残りで 1.0)。
3. 輝度の質感との関係 (正解 Y の局所の質感で 3 等分):
   - 本家: 質感の強い所ほど色差を除く量が減る。
     ・park_joy p_y3 Cb の β: 質感の低い所 0.85 → 中 0.64 → 高 0.02
     ・Cr の β: 0.92 → 0.79 → 0.40
     ・sintel Cr でも 0.93 → 0.89 → 0.83
   - 当方: 質感の強い所で、むしろ除く量が増える (park_joy Cb は質感の高い所で 7.9、足した雑音は 1.6)。
4. 輝度の高さとの関係: 本家の β は、park_joy Cb で暗部 0.73、明部 0.07〜0.09 と大きく違う。一方 sintel と old_town では、明るさによる差は小さい。
   推測: 明るさそのものではなく、park_joy の明るい部分の内容 (葉や空の色の細部) によるとみられる。
5. 輝度と色差の結びつき: RGB に足した雑音は、Y と色差に負の相関を持つ (corr(nY, nCb) −0.44〜−0.55、corr(nY, nCr) −0.37〜−0.43)。
   - 本家: 除いた量どうしの相関 corr(mY, mCr) は −0.21〜−0.42 で、雑音の相関に近い。
   - 当方: −0.08〜−0.25 で、雑音の相関から離れている。Cb は両者とも −0.30〜−0.53 で近い。

推測 (出力から読める範囲での手がかり):
- 本家の色差の処理は、帯域ごとの雑音の大きさに合わせて弱めていて、色差を雑音以上には削らない。当方は CHROMA_GAIN の分だけ強すぎる。
- 本家は、輝度 (またはその色差自身) に構造がある所で色差の処理を弱めているとみられる。この観測だけでは、輝度を手がかりにする
  ガイド型か、色差自身の局所の信号を見る適応型かを区別できない。色差の細部は輝度の質感と重なるため。
- Y と Cr の相関が雑音どおりに保たれていることは、本家が雑音を RGB の各チャンネル (またはプロファイルの 6 面
  RGB+YCrCb のモデル、Agents.md §6.5) として扱い、成分間の相関を含めて推定・除去していることと整合する。
  当方は Y・Cb・Cr を独立に扱う。ただし、この相関は除いた量の大きさにも影響されるので、弱い手がかりにとどまる。

## 5. まとめ (観測)
- 素材の粒状 (old_town) は、本家も当方もほぼ同じだけ削る。正解比で入力より悪くなるのは両者に共通の性質。
- 当方と本家の差の大部分は、(a) 速い動きで画を時間方向に混ぜること (park_joy の大きく動く区分、低域の除去)、
  (b) 粗い帯域と色差で雑音を見積もり過ぎること、による。本家は雑音を少し残してでも、どの帯域でも雑音以上は削らない。
- 色差: 本家は除く量を雑音の RMS 以下に抑え、輝度に質感のある所では色差の処理を弱めている。
