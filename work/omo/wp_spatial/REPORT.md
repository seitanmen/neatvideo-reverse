## 1. 要約 (要素ごとの結論)

1. **呼び出し構造 (観測)**: 空間フィルタは `Filter 0x9ac2b0` → チャンク分割 → CPU 経路
   `FUN_009adc8c` → 1 チャンク `FUN_009ae918`。RGB → 色変換 (プロファイルの色モード) →
   3 面それぞれ `FUN_0098edb0` (マルチスケール縮小) → クロマ ブレンド (profile+0x110..0x11c)。
   σ マップは `FUN_009aae90` が プロファイルの段別・輝度別テーブル + 色行列から画素単位で構築。
2. **分解 (観測)**: 間引きラプラシアン金字塔 5 段。`blur = box3×3(L_k)` → `L_{k+1} = ½↓(blur)`
   (2×2 平均) → `B_k = L_k − ↑(L_{k+1})` (↑ = (3,1)/4 分離双一次 ×2)。v5 の非間引き a-trous
   との違いはここが最大。
3. **縮小核 (観測)**: `FUN_00990f74` = 白色化 `W = B_k/(σ_k+9.4433e-4)` → `R = √(box3×3(W²))` →
   `X = W·clamp((2t−R)/t, 0, 1)`、`t = 1.1·cfg[k]·|model[+0x780+組·5+k]|`。通常経路の出力は
   `dst = (1−フラグ)·(−model[+0x14+4k])·X` (model 側の σ 乗数。cfg の amount は適応経路のみ)。
   呼び出し元が `ACC = ↑(ACC) + dst·σ` を累積し、最後に `OUT = 入力 + ACC`。
4. **方向フィルタ (観測・未実装)**: 組 1..4 は 4/8/16 方向の線フィルタ (FUN_00990448/009944c0、
   画素ノイズ推定と同じ表) + 大口径構造判定 (model+0x7e4/+0xe24) + 自己相似パターン保護
   (FUN_009ad06ec 系、BuildNoiseModel の組 4 と同じ)。数値詳細は未解読。
5. **参照実装 `src/nv_spatial.py`**: 上記 1〜3 の高速経路 (方向なし) を v5 と同じ署名・同じ σ 成分
   (curve × band_ratio × Noise Level × √rv) で移植。σ は段解像度へ 1/2 縮小、しきい値倍率は
   `P["genuine_t"]` (既定 1.0 → t = 1.1)。
6. **区間 A/B 実測 (観測)**: v5 既定は両区間で公式基準値を 0.003 dB 以内で再現 (ランナー妥当)。
   空間段差し替えは t=1.0 で Y −0.80/−0.50 dB、t=1.5 で Y −0.12/−0.07 dB、
   色差は −0.35〜−0.70 dB (v5 は本家出力への較正込み)。**本家構造でもしきい値を上げれば
   v5 とほぼ同等の Y が出る。構造差そのものは小さい。**
7. **ビット照合**: 0 件実施 (既存 nvh サブコマンドに空間フィルタ経路が無い)。ハーネス要求を
   `harness_request.md` + `nvh_patch.diff` として提出、照合スクリプト `verify/verify_shrink.py`
   を同梱 (追加後すぐ実行できる)。
